Understanding and Extending Exclusive Self Attention

Arya Vohra & Aleksandr Popov

Introduction & Background

  • Exclusive Self Attention (XSA) (Zhai et al., 2026) is a modification to the self-attention operation in transformers. For each attention head, it orthogonalizes the attention outputs against the current token's value vector.
  • For head $h$ at position $i$, XSA projects the attention output $y_{h,i}$ onto the orthogonal complement of the self-value vector $v_{h,i}$:
Standard Attention $\displaystyle y_{h,i}=\sum_{j\leq i} a_{h,ij}v_{h,j}$
Exclusive Self Attention (XSA) $\displaystyle z_{h,i} = \left( I - \frac{v_{h,i}v_{h,i}^{\top}}{\|v_{h,i}\|^2} \right) y_{h,i}$
  • Core Intuition: Attention should prioritize modeling contextual information from other tokens, since information about the current token is already accessible through the residual stream and subsequent feedforward network (FFN).
  • XSA also acts as an implicit attention sink. By removing the attention component along $v_i$, models can discard attention mass by attending heavily to the self-value. This allows tokens to "attend to nothing" without an explicit sink token.

Existence of the Phenomenon

  • To observe the phenomenon motivating XSA, we trained an 11-layer GPT-2-style model on FineWeb and analyzed the alignment between attention outputs $y_i$ and self-values $v_i$. We observe consistent, strong $v_i$-alignment across heads and layers.

Training an XSA Model

  • We implemented 3 approaches to XSA's orthogonalization principle, each w.r.t. a different space
  • Value Space (author's approach): Projects $y_{h,i}$ against $v_{h,i}$ on a per-head basis.
  • Residual Space: Projects the post-$W_o$ final attention output $o_i$ against the residual token representation $x_i$:
    $$o_i'= o_i-\frac{o_i^\top x_i}{\|x_i\|^2}x_i$$
  • Model Space: Projects $o_i$ against the combined subspace span of all head self-values in the model space. Let $u_{h,i}=W_o^{(h)}v_{h,i}$, $U_i=\operatorname{orth}(u_{1,i},\ldots,u_{H,i})$, and:
    $$o_i'=(I- U_iU_i^\top)o_i$$

Mechanistic Interpretability & Interventions

  • Sinking Hypothesis: We observed that XSA models allocate significantly higher attention mass towards the self-token, validating that it acts as an implicit sink.

XSA 0.1824 0.1475 0.1611
  • Causal Interventions: We took a fully-trained XSA model and perturbed or disabled the XSA projections at evaluation time to examine the causal mechanisms underlying XSA.
Eval-Time Intervention \(\ell_{\text{eval}}-\ell_{\text{intervention}}\) Interpretation
No XSA -1.9176 XSA adjusts learning dynamics, this is unsurprising.
Project out random vector (Shuffle value projection) -0.9487 Some of the gains from XSA can be attributed to norm modulation, but clearly this doesn't explain everything.
Force \(a_{ii}\) = 0 (Zero out diagonal mass) -0.2557 Eliminating the most explicit attention sink path only decreases loss slightly $\implies$ implicit attention sinking through self-aligned context tokens.
Add back $v_i$ context post-XSA -1.3348 Adding back context-derived $v_i$-parallel components increases loss a lot $\implies$ removal of redundant context seems to be important (a separate improvement of XSA).
Add back diagonal post-XSA -0.5702 Adding back the removed diagonal component post-XSA also hurts, but less so $\implies$ context redundancy removal is more explanatory of XSA's action than attention sink.

Improving XSA in NanoGPT Speedrun

  • The current Modded-NanoGPT world-record implementation contains a quasi-attention sink called "Sparse Attention Gates".
  • We demonstrated that XSA naturally behaves as an attention sink hence we hypothesized that Sparse Attention Gates are redundant. Removing these yielded a new WR!

Conclusions & Future Work

  • Valuable Inductive Bias: Confirms the intuition of self-attention as a contextual mixing operator. Projecting attention outputs to be orthogonal to the self-value improves sample efficiency.
  • Implicit Sinks: Confirms that XSA provides a robust, parameterless alternative to explicit attention sinks. Models learn to place redundant attention mass on diagonal indices and other self-aligned directions.
  • XSA cannot, however, be blindly dropped in. Learning to weight the orthogonal complement projection $\in[0,1]$ yields faster convergence.
